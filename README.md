# Партнёрка — прототип лендинга

Прототип главной страницы сервиса для запуска партнёрских, реферальных и амбассадорских программ (partnerka.io).

- Один файл `index.html`: Tailwind CSS через CDN, шрифт Onest, без сборки.
- UI-референс: synthesia.io. Целевое разрешение 1920×1080, адаптив до 375px.
- Формы в модалке не отправляют данные, логотипы брендов и цифры в мокапах — заглушки.

Открыть: https://serjnsk.github.io/partnerka_io/
